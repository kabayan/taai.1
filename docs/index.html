notif Web Flasher v1.0.0

M5Stack AtomS3 / Atom Lite (標準 / Voice 各バリアント) に notif ファームウェアをブラウザだけで書き込み、 書込後はそのままブラウザから BLE 制御できるツール。 PC への esptool / Arduino IDE / PlatformIO のインストール不要。

ファーム書き込み → Web BLE 制御 → 音声対話コントロール →

書込 → 制御を 1 ブラウザで完結。 Web Bluetooth および 音声対話は Chromium 系のみ対応（Android / PC Chrome推奨）。

使い方

  1. 対象機種 (AtomS3 / Atom Lite、 標準 or Voice) を USB-C ケーブルで PC に接続
  2. 上のボタンから書き込みページを開く
  3. 「機種選択」で 機種 (AtomS3 / Atom Lite) × バリアント (標準 / Voice) を選ぶ
  4. 「USB シリアル接続」 → ポート選択 → 「ファーム書き込み開始」

対象機種

機種SoC / USBファーム機能flash
M5Stack AtomS3 + AtomS3-IR ESP32-S3 / 内蔵 USB CDC BLE + LCD 128×128 + IR + Stepper + GPIO 8MB / huge_app.csv
M5Stack Atom Lite ESP32-PICO-D4 / 外付け USB-Serial chip (FTDI / CH9102 / CH340 / CP210x) BLE + Neopixel LED + IR + GPIO (LCD なし) 4MB / huge_app.csv
M5Stack AtomS3 + Atomic Voice Base ESP32-S3 / 内蔵 USB CDC BLE + LCD 128×128 + IR + Voice + GPIO 8MB / factory 3MB + LittleFS 4.94MB
M5Stack Atom Lite + Atomic Voice Base ESP32-PICO-D4 / 外付け USB-Serial chip BLE + Neopixel LED + IR + Voice + GPIO (LCD なし) 4MB / factory 1.6MB + LittleFS 2.3MB

必要環境

  • ブラウザ: PC 用 Chrome / Edge (デスクトップ版)。 スマホ / タブレット / iPad Chrome は WebSerial 未対応
  • ケーブル: AtomS3-IR の USB-C ポートに接続できるケーブル (データ通信対応のもの)
  • OS: Windows / macOS / Linux。 Linux は dialout グループ等の USB アクセス権限が必要なことあり

動作原理

本ページは esptool-js (Espressif 公式 JS 版 esptool) + WebSerial API を使い、 ブラウザから直接 ESP32-S3 のブートローダーに接続して書き込みを行う。 サーバー通信はリリースアセット (.bin) の fetch のみで、 書き込み処理自体は全てブラウザ内で完結する。
