Notif Web BLE Control v10.6.0

notif v10 ファーム (atomlite / atoms3-ir / atomlite-voice / atoms3-voice) を Web Bluetooth API 経由でブラウザ単体から制御する。 PC Chrome / Edge (HTTPS or localhost) または Android Chrome で動作。 iOS Safari は Web Bluetooth 非対応。

3. GPIO (CMD_GPIO 0x30, caps:gpio)
PULSE 時 val=duration_ms / MODE 時 val=INPUT=0/OUTPUT=1/INPUT_PULLUP=2 等
4. IR Send (CMD_IR_SEND 0x40, caps:ir_tx)
RAW: timings は u16 LE の microseconds 配列、 hex 入力は LE u16 を 2 byte ずつスペース区切り (例: 30 23 18 23 = [0x2330, 0x2318])
5. IR Recv 学習 (CMD_IR_RX_START 0x41 / STOP 0x42, caps:ir_rx)
学習開始後、 リモコンを押すと IR_RX char に notify が来て下記に表示される。 atomlite は caps:ir_rx を申告するが、 IR モジュール物理接続 (atomlite Grove G32 / atoms3-ir Grove G2) を要する点に注意 (接続有無はユーザー判断)。

    6. RGB LED (CMD_RGB_LED 0x44, caps:rgb_led)
    atomlite は内蔵 SK6812 1 個 (index=0)、 範囲外は ERR_OUT_OF_BOUNDS
    7. Voice テキスト再生 (CMD_VOICE 0x60, caps:voice)
    JP 3 byte/字 で MTU 244 byte 上限 (約 81 文字)。 CHAR_MAP 不在文字は silent skip、 再生中重複は ERR_VOICE_BUSY (0x08) で reject。 atomlite-voice / atoms3-voice (Atomic Echo Base + ES8311 検出) でのみ enable。 音量 (CMD_VOICE_VOLUME 0x61) は sticky で、 Send Voice 時にも先に送信される。
